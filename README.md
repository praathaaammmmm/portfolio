# Pratham Singh — Portfolio

Personal portfolio for Pratham Singh, an AI systems and product developer based in Delhi, India.

## Live site

[portfolio-praathaaammmmm.vercel.app](https://portfolio-praathaaammmmm.vercel.app)

## Highlights

- AI-powered products, RAG workflows, and multi-agent experimentation
- Production-minded Python and FastAPI backend development
- Modern web work with TypeScript, Next.js, React, and Vite
- Android product development with Kotlin, Jetpack Compose, Ktor, PostgreSQL, and Docker
- Arch Linux and Hyprland systems customization

## Featured work

- **[Receptionist Demo](https://github.com/praathaaammmmm/receptionist_demo)** — AI-assisted dental front-desk demo with appointments, callbacks, QR check-in, analytics, and voice-demo flows.
- **[Switch On](https://github.com/praathaaammmmm/switch_on)** — Android-first electronics repair platform for diagnostics, bookings, repair tracking, payments, and warranties.
- **[Dental QR](https://github.com/praathaaammmmm/Dental_QR)** — privacy-aware QR campaign and offer-management platform for dental clinics.
- **[Zenith](https://github.com/praathaaammmmm/zenith)** — multi-agent, RAG-powered startup-intelligence platform.
- **[Linux-DotFiles](https://github.com/praathaaammmmm/Linux-DotFiles)** — developer-focused Arch Linux + Hyprland environment.

## Run locally

```bash
python3 -m http.server 4173
```

Then open <http://localhost:4173>.

## Deployment

The portfolio is deployed on Vercel. Pushes to `main` trigger a production deployment.
